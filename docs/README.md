## 文件慣例

| 標記 | 意義 |
|---|---|
| ✅ | 已完整實作 |
| 🟡 | 今天可行，但需要手動設定 |
| 🚧 | 規劃中，**尚未實作** |
| ❌ | 刻意不做 |
| ⚠️ | 需要特別注意的取捨或風險 |

文件中出現的所有預設值都對應到程式碼中的實際預設。若發現不符，那是 bug —— 請[開 issue](https://github.com/pcpcchen-coder/FamilyRecorder/issues)。
